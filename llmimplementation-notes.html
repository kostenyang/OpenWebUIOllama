    globalIPSettings=vim.vm.customization.GlobalIPSettings(

        dnsServerList=['10.0.0.200', '10.0.0.1']),
    nicSettingMap=[vim.vm.customization.AdapterMapping(
        adapter=vim.vm.customization.IPSettings(
            ip=vim.vm.customization.FixedIp(ipAddress='10.0.0.63'),
            subnetMask='255.255.254.0',
            gateway=['10.0.0.1']))],
    options=vim.vm.customization.LinuxOptions())

spec = vim.vm.CloneSpec(
    location=vim.vm.RelocateSpec(datastore=ds, pool=cluster.resourcePool),
    template=False, powerOn=True, customization=custom)

14:50 systemd override → bind 0.0.0.0:11434 OK

mkdir -p /etc/systemd/system/ollama.service.d
cat > /etc/systemd/system/ollama.service.d/override.conf <<EOF
[Service]
Environment="OLLAMA_HOST=0.0.0.0:11434"
Environment="OLLAMA_ORIGINS=*"
Environment="OLLAMA_KEEP_ALIVE=24h"
EOF

systemctl restart ollama

離線安裝 — 已準備腳本,未實測

三段式:

  1. 有網機器跑 scripts/prepare-offline-bundle.sh /tmp/out → 抓 ollama-linux-amd64.tar.zst (1.2 GB) + zstd.deb + 從本機 /usr/share/ollama/.ollama/models/ 把 llama3.2:3b 的 manifest + blobs copy 出來
  2. tar czf bundle.tgz 整包 → scp 到 air-gapped 目標
  3. 目標機器跑 scripts/install-offline.sh /tmp/out:dpkg -i zstd.deb → zstd -d | tar -x → 寫 systemd unit + override → copy 模型 blobs → systemctl enable --now

關鍵點:zstd 一定要先裝(focal minimal 沒裝),不然 tarball 解不開。

學到的

  • 同網段 clone running VM 是地雷:cloned VM 開機後 IP 撞,而且如果 source 就是你的 jump host(像 mcp-server)會把自己鎖在外面。用 template + customization spec 一次到位,別走 clone-then-fix 那條路。
  • pyvmomi 8.0+ 鎖 Python 3.10+:Ubuntu 20.04 / Python 3.8 上要 pip3 install 'pyvmomi<8.0'。
  • vCenter REST /api/vcenter/vm 不回 template(template=True 的 VM 不在 list)。要 list template 必走 SOAP / pyvmomi。
  • Ollama 2024 後改用 .tar.zst:Ubuntu 20.04 minimal 沒 zstd,install.sh 會明確報錯 — 不是神祕失敗。
  • Ollama 預設只 bind 127.0.0.1:不套 systemd override 任何外部主機都連不到。
  • FastMCP SSE session 會累積:長時間操作可能 trigger,看到 MCP tool 全 hang 就 systemctl restart vcf-mcp(會斷自己 SSE,等 1–3 分鐘 reconnect)。
